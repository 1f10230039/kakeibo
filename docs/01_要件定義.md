# 要件定義

第4稿（2026-10-06。段階②の予算を「全体だけ」に決めた）

凡例：✅ 決定 ／ ⬜ 未確定（🟡 案はすべて 10/6 に承認済み）

---

## 1. 目的

楽天の家計簿アプリは広告が多すぎて見にくい。**広告なしで、今月いくら使ったかがパッとわかる**自分専用の家計簿を作る。

あわせて、数字と文字ばかりで退屈になりがちな家計簿の見た目を、**余白と写真を生かしたエレガントな画面**にする。

## 2. 前提と制約

| # | 内容 | 状態 |
|---|---|---|
| C-01 | 使うのは本人だけ（共有しない） | ✅ |
| C-02 | 見る端末は **iPhone と PC の両方** | ✅ |
| C-03 | **サブスク（月額課金）が必要なサービスは使わない**。無料枠で動かす | ✅ |
| C-04 | 手間は極力自動。自動化できない項目は、ある程度の手入力を許容する | ✅ |
| C-05 | 本人は Gmail のメールを定期的に削除する。消されても集計が壊れないこと | ✅ |
| C-06 | 「今月」は**カレンダー通りの1日〜末日** | ✅ |
| C-07 | 支出をどの月に数えるかは**利用日（カードを使った日）**で決める。引き落とし月ではない | ✅ |

## 3. 使う口座とデータの出どころ

| 口座 | 用途 | アプリでの扱い |
|---|---|---|
| 楽天カード（Mastercard） | 支出のほぼ全部。毎月27日に楽天銀行から引き落とし | 利用通知メールから**自動**で取り込む |
| 楽天銀行 | 収入の受け取り、カード代の引き落とし | 収入・残高の出どころの候補（段階③で判断） |
| 楽天証券 | 積立NISA | 資産推移の出どころ（段階③。自動の方法は未確認） |

### 3.1 楽天カードの利用通知メール（調査済み・10/6）

| 種類 | 届く時期 | 書いてあること |
|---|---|---|
| 【速報版】カード利用のお知らせ | 最短で翌日 | 利用日・利用者・利用金額 |
| カード利用のお知らせ（確定版） | 最短で2日後 | 利用日・**利用先**・利用者・支払方法・利用金額・**支払月**。1通に複数件が入ることがある |

送信元は `info@mail.rakuten-card.co.jp`。出典：[楽天カード FAQ](https://support.rakuten-card.jp/faq/show/72?site_domain=guest)、実際のメール2通（2026-10-02 受信）。

**通知されないもの**（規約 第3条第2項より抜粋）：
- 利用金額が500円以下の利用
- キャンセルになった利用。確定版メールにも「キャンセル・取消のご案内については配信されません」とある
- キャッシング
- 加盟店側の都合で情報が遅れた場合、システムメンテナンスのとき など

出典：[カード利用お知らせメールサービス利用規約](https://www.rakuten-card.co.jp/agreement/information_mail/)

→ **メールだけでは支出の全部はとれない**。補う手段を機能要件（F-07, F-08）に入れる。

## 5. 機能要件

### 段階①

| # | 機能 | 内容 | 状態 |
|---|---|---|---|
| F-01 | メールの自動取り込み | 楽天カードの利用通知メールを定期的に読み、利用日・利用先・金額などを記録する | ✅ |
| F-02 | 取り込み済みの印 | 取り込んだメールの番号をシートに残し、同じメールを二度取り込まない。その後に本人がメールを消しても記録は残る。Gmail のラベルは付けない（Gmail を読み取り専用の権限にするため。10/6 変更） | ✅ |
| F-03 | 速報版と確定版を二重に数えない | 速報版で先に金額を出し、確定版が来たら置き換える | ✅ |
| F-04 | ホーム画面 | 今月の支出、今月の収入、トータルの残高、期間ごとの支出トップ、次の27日の引き落とし予定額 | ✅ |
| F-05 | 統計画面 | 収入・支出の棒グラフ（期間を切り替えられる）、その下に利用一覧（いつ・何に・いくら）、カテゴリ別の円グラフ | ✅ |
| F-06 | カテゴリの振り分け | 「利用先→カテゴリ」の対応表で自動で振り分ける。初めての利用先は「未分類」に入れ、本人が一度決めたら次からは自動。カテゴリは 6.1 | ✅ |
| F-12 | 1件ずつのカテゴリ変更 | 同じ利用先でも中身が違うもの（例：APPLE COM BILL がサブスクのときとアプリ購入のとき）は、その1件だけカテゴリを変えられる | ✅ |
| F-07 | 手入力の支出 | 500円以下の買い物、現金払いなどを「＋」から入れる | ✅ |
| F-08 | 月1回の照合 | e-NAVI の明細 CSV（確定分。PC からのみ取得できる）を読み込み、メールの記録との差（キャンセル・漏れ）を見つける | ✅ |
| F-09 | 過去分の取り込み | 消してしまった9月以前の分を e-NAVI の CSV から一度だけ取り込む | ✅ |
| F-10 | 金額を隠す | ボタン1つで画面の金額を伏せる（人前で開く用） | ✅ |
| F-11 | タブバー | 画面下のタブで各画面を行き来する | ✅ |

### 段階②

| # | 機能 | 内容 | 状態 |
|---|---|---|---|
| F-21 | 予算の設定 | 月の予算（**全体だけ**）を決める。毎月同じ金額を基本にし、変えたい月だけその月の金額で上書きする | ✅（10/6 本人） |
| F-22 | 予算に対する出費 | 予算に対して今いくら使ったか、残りいくらかを表示する。あわせて、1日あたりあといくら使えるか、今日までの目安（予算×今日までの日数÷月の日数）も出す。ホームにも予算の残りを出す | ✅（10/6 本人） |

### 段階③

| # | 機能 | 内容 | 状態 |
|---|---|---|---|
| F-31 | 収入の記録 | 楽天銀行の取引通知メールから自動で取り込む。できなければ手入力 | ⬜ 実物のメールを1通見てから判断 |
| F-32 | 残高 | 楽天銀行の残高を表示する | ⬜ 取引通知メールに残高が載るかを確認。載らなければ月1回の手入力 |

### 6.1 カテゴリ

カテゴリ（11個）は ✅ 本人の指定（10/6）。グループ分けも ✅（10/6）。

| グループ | カテゴリ ✅ |
|---|---|
| 暮らし | 食費、日用品、交通費、健康・医療 |
| 固定費 | サブスク、通信費 |
| たのしみ | 趣味・娯楽、衣服、美容、交際費 |
| その他 | その他 |

- 振り分けが決まっていない利用は「未分類」に入れる（カテゴリには数えず、決めるまでの待ち場所）

**持たないデータ**：カード番号、口座番号、パスワード、暗証番号。

## 7. 非機能要件

| # | 項目 | 内容 | 状態 |
|---|---|---|---|
| N-01 | 費用 | 0円。無料枠で動くもの（Google Apps Script、静的サイトの無料ホスティング）だけを使う | ✅ |
| N-02 | 安全性 | 家計のデータは合言葉を知っている人しか読めないこと。完成後に、合言葉なし・間違った合言葉で本当に読めないかを実際に試して確かめる | ✅ |
| N-03 | 自動の頻度 | メールの取り込みは1時間おき程度 | ✅ |
| N-04 | 無料枠に収まること | Apps Script の無料（gmail.com）の上限：トリガー実行は合計90分/日、1回6分まで、メールの読み書き2万件/日。出典：[Apps Script Quotas](https://developers.google.com/apps-script/guides/services/quotas) | ✅ |
| N-05 | 表示 | iPhone ではホーム画面に追加して PWA として開く。PC はブラウザ（インストールもできるとよい） | ✅ |
| N-06 | 画面の幅 | iPhone の幅を基準に作り、PC では広い画面に合わせて並べ替える | ✅ |
| N-07 | オフライン | 電波がないときは、最後に取得したデータを表示する | ✅ |
| N-08 | 見た目 | 余白を生かしたエレガントな雰囲気。写真を使い、数字ばかりの退屈な画面にしない。画面の構成は参考画像1・2枚目、雰囲気は3枚目 | ✅ |
| N-09 | 写真の権利 | 使う写真は本人が撮ったもの、または利用条件を確認した素材だけ | ✅ |
| N-10 | 説明できること | 仕組み（どこからデータが来て、どう計算しているか）を docs/ で説明できる状態にする | ✅ |

## 8. 作らないもの（スコープ外）

- 楽天銀行の API との連携（電子決済等代行業者向けで、個人では実質使えない。10/6 調査）
- e-NAVI などへの自動ログイン（スクレイピング）。パスワードをスクリプトに置くことになるため
- 他の人との共有、家族カード
- 振込・積立設定の変更など、お金を動かす操作はいっさい行わない（✅ 10/6）
