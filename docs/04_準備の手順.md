## 0. 貼り付けるファイルを作る（Claude がやる／やってある）

```bash
node gas/build.js
```

`gas/dist/` に次の2つができる。

- `取り込み.gs`：コードの全部（共通.gs・取り込み.gs・実行.gs をまとめたもの）
- `取り込み_appsscript.json`：プロジェクトの設定（タイムゾーン・権限・Gmail API を使うこと）

## 1. Apps Script のプロジェクトを作る

1. PC のブラウザで https://script.google.com を開く（楽天カードの通知が届く Google アカウントでログインした状態で）
2. 左上の「新しいプロジェクト」を押す
3. 上の「無題のプロジェクト」を押して、名前を **家計簿 取り込み** にする

## 2. 設定ファイルを入れる

1. 左の歯車（プロジェクトの設定）を開く
2. 「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れる
3. 左の `<>`（エディタ）に戻ると、ファイルの一覧に `appsscript.json` が出ている
4. `appsscript.json` を開き、中身を全部消して、`gas/dist/取り込み_appsscript.json` の中身を貼る
5. 保存（Ctrl + S）

この設定に、Gmail API を使うことと、許可してもらう権限の3つが書いてある。

## 3. コードを入れる

1. `コード.gs` を開き、中身を全部消して、`gas/dist/取り込み.gs` の中身を貼る

# GAS ②「家計簿 API」

アプリ（PWA）から呼ぶ入口。**スプレッドシート「家計簿データ」に付属させて作る**（GAS ① とは別）。権限は「このスプレッドシートだけ」で、Gmail には触れない。

## 6. 付属の Apps Script を作る

1. スプレッドシート「家計簿データ」を開く
2. 上のメニューの「拡張機能」→「Apps Script」
3. 開いた画面の上の「無題のプロジェクト」を押して、名前を **家計簿 API** にする
4. 歯車（プロジェクトの設定）→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
5. `appsscript.json` の中身を `gas/dist/API_appsscript.json` に置き換えて保存
6. `コード.gs` の中身を `gas/dist/API.gs` に置き換えて保存

## 7. 合言葉を作る

1. 関数の選択で **makeKey** を選んで実行（最初は別の関数が選ばれている）
2. 許可の画面が出たら、手順4と同じように進める。求められる権限が**「このアプリが含まれるスプレッドシートの表示と管理」のような、このスプレッドシートだけの権限1つ**であることを確かめてから許可する
   - ⚠️ 画面の正確な言い回しは未確認。「すべてのスプレッドシート」「Gmail」が出てきたら、許可せずに止めてClaude に教えて
3. 実行ログに `合言葉（PWA に入れる）: ……` と64文字が出る
   - **パスワード管理アプリなど、安全な場所に控える**。AI とのチャットには貼らない（会話の記録に残るため）
   - スプレッドシート側には合言葉のハッシュだけが保存される。忘れたら makeKey をもう一度実行すれば作り直せる（前の合言葉は使えなくなる）

## 8. ウェブアプリとして公開する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 歯車（種類の選択）→「ウェブアプリ」
3. 次のように設定して「デプロイ」
   - 説明：`家計簿 API`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 出てきた「ウェブアプリの URL」（`https://script.google.com/macros/s/……/exec`）を控える
   - URL はClaude に送ってよい。URL だけでは何も読めない作りなので、Claude が「合言葉なしで本当に読めないか」を外から試すのに使う

## 9. 本人が確かめる（合言葉が必要なので、本人が自分のパソコンで）

Git Bash で、`合言葉` と `URL` を自分のものに書き換えてから実行する。

```bash
curl -sL -H 'Content-Type: text/plain;charset=utf-8' -d '{"key":"合言葉","action":"getData","params":{"from":"2026-09","to":"2026-10"}}' 'URL'
```

`{"ok":true,"data":{"transactions":[…3件…],…}}` が返れば、**「このスプレッドシートだけ」の権限でもウェブアプリとして動く**ことが確かめられる。`{"ok":false,"error":"サーバーの中で失敗しました"}` なら、その権限ではシートを開けなかったということなので、Claude に伝える（権限を広げる相談をする）。

コードを直したときは、「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」で、同じ URL のまま新しくできる。
