## 2. 画面遷移

### 2.1 タブバー ✅

```
[ ホーム ]  [ 統計 ]  [ 予算 ]  [ 資産 ]
```

- タブは4つだけ。「＋」は置かない（✅ 10/6）
- 記入が必要なものは、**ホームの「やること」のボタンで促す**（✅ 10/6。中身は S-01 の 5）
- メニュー（S-08）はタブに入れず、ホームの右上のアイコンから開く（✅）
- 段階①の間、予算・資産のタブは「準備中」の画面にする

### 2.2 遷移の一覧

```

 └─ 合言葉が未保存 → S-00 合言葉 → S-01 ホーム

S-01 ホーム
 ├─ 右上のアイコン → S-08 メニュー
 ├─ 目のアイコン → 金額を隠す／出す（F-10。画面は変わらない）
 ├─ やること「未分類が◯件」 → S-06 未分類の振り分け
 ├─ やること「CSV で照合する」（月初だけ） → S-09
 ├─ やること「今月の資産を記録する」（25日〜月末）／「先月の資産を記録する」（1〜7日） → 資産の記録のシート
```

## 3. 各画面の配置

上から順に並べる。はすべて 10/6 に承認済み。

### S-01 ホーム

1. **写真のヘッダー**（画面の上 4割ほど）：季節や月で変わる写真を置き、その上に「10月」と挨拶、右上にメニューと目のアイコン
2. **今月の支出**：写真の下端に重なる白いカードに、大きな数字を1つだけ置く。その下に小さく「先月の同じ日まで：¥◯◯」（✅ 10/6）。予算があるときは、その下に細い横棒（使った割合と今日までの目安の縦線）と「予算の残り ¥◯◯」（✅ 10/6。押すと S-03）
3. **収入・残高の行**：収入｜残高 を横に2つ並べる。収入＝今月の入金の合計（押すと S-11）。残高＝楽天銀行の記録 − 記録のあと〜次の引き落とし日までの引き落とし。出し方は「残高 ⓘ」に入れる（10/7）。その下に小さく「資産の合計 ¥◯◯」（✅ 10/6 本人）
4. **固定費**：「固定費 ⓘ｜¥◯◯（今月の見込み）›」の横長のカード（✅ 10/7 本人。「今月の見込み・先月…」の文は分かりにくいのでなくし、出し方は ⓘ に）。押すと S-12
5. **次の引き落とし**：「10/27 引き落とし予定 ¥◯◯」の細い帯
6. **やること**：記入が必要なものがあるときだけ、ボタンの形で出す。何もなければこの欄ごと消える
   - 「未分類が3件あります」→ S-06
   - 「先月分を CSV で照合する」（毎月1〜7日ごろだけ）→ S-09
   - 「今月の資産を記録する」（25日〜月末）／「先月の資産を記録する」（1〜7日。記録日は先月末にしておく）。その期間（前の25日から）にもう記録があれば出さない → 資産の記録のシート
   - 「予算を決める」（予算がないときだけ）→ S-03
   - 欄の右端に、いつでも押せる「記録する」（手入力 S-07）
7. **支出トップ**：期間の切り替え（今週／今月。開いたときは今月・10/6 本人）と、横にスクロールするカテゴリのカード。カードにはカテゴリの写真を置き、上に順位・カテゴリ名・金額を載せる
8. **最近の利用**：3件だけ。表示は S-02 の一覧と同じ（用途だけ）

### S-02 統計

1. **見出し**「統計」と、期間の単位の切り替え（週／月／年）
2. **グラフの種類の切り替え**：「棒｜円」の小さな切り替え
3. **期間の表示**：「‹ 2026年10月 ›」。左右の矢印でも、グラフのスワイプでも前後の期間へ動く
4. **グラフのカード**
   - 棒グラフ：支出の棒（収入と切り替え）。棒の単位は、週なら1日ずつ、月なら1週ずつ、年なら1か月ずつ（✅ U-11）
     - 色：支出の棒は円グラフと同じグループの色で積み上げる（下から 暮らし・固定費・たのしみ・その他・未分類）。下に、その期間に使ったグループの色の見本。収入は1色（✅ 10/7）
     - 縦の目盛り：右に、きりのいい金額（1・2・2.5・5 ×10ⁿ 円の間隔）の点線を4本まで。1万円からは「2万」の形。棒の高さはいちばん上の線を基準にする。金額を隠しているときは線だけ（✅ 10/7）
     - 横の目盛り：週は曜日、年は「1月」〜「12月」。月は棒ごとに書かず、左端と右端の日付（例：9/1・9/30）だけ（✅ 10/7）
     - 棒を選ぶと、ほかの棒が薄くなり、上に期間（月は「9/8〜9/14」、週は「10/6（火）」）と金額が出る。金額は棒より横に広いので、横に重なるとなりの棒のほうが高いときは、その棒より上に出す（✅ 10/7）
   - 円グラフ（ドーナツ型）：グループ4色で比率を見せ、真ん中に合計。タップでカテゴリの内訳
5. **利用一覧**：日付ごとの見出しの下に「カテゴリの印｜**用途（カテゴリ名）を大きく**＋小さく名前（例：サブスク　YouTube Premium）｜金額」。名前は、この利用だけの名前 → 店の表示名 の順。どちらもなければ用途だけ。利用先（店名）は一覧には出さず、S-05 で見る（✅ 10/6）。絞り込み中は一覧の上に「◯◯で絞り込み中 ×」
   - 並べ方：「一覧」の見出しの右の「日付順｜カテゴリー別」で切り替える（✅ 10/7）。カテゴリー別は、カテゴリーごとの見出し（名前・件数・合計）を合計の多い順に並べ、中は新しい順。見出しにカテゴリーが出るので、行の名前は この利用だけの名前 → 店の表示名 → カテゴリー の順。収入の一覧では「名前別」（バイト代・お小遣い…）

> **スワイプがぶつかる問題**：はじめは「棒⇄円」を横スワイプで切り替える案だったが、「前後の期間へスワイプ」も横の動きになる。両方は同じ手の動きに割り当てられないので、**横スワイプ＝期間、棒／円＝切り替えボタン**に分けた。

### S-03 予算（段階②）

予算は全体だけ（U-02 → 10/6 本人）。

1. **今月の残り**：大きな数字（使いすぎたら「オーバー」と、その額を注意の色で）。その下に、使った割合の横棒と、今日までの目安の縦線。「使った ¥◯◯（◯%）」「予算 ¥◯◯」
2. **2つの小さいカード**：「1日あたり」（月末まで、今日を入れて残りの日数で割る。使いすぎたら —）／「今日までの目安」（目安より ◯円 少ない・多い）
3. **予算の決め方**：「毎月の予算」と「◯月だけの予算」の2行。押すと金額を入れるシートが開く。その月だけの予算があれば毎月の予算より優先し、「やめる（毎月の予算に戻す）」で戻せる
4. 予算がないときは、1・2 の代わりに「予算を決める」ボタンの入ったカード

### S-04 資産（段階③）

項目は楽天銀行と楽天証券 NISA の2つ（✅ 10/6 本人）。

1. **資産の合計**（いちばん新しい記録。その日に入れなかった項目は前の記録の金額）と「◯/◯ の記録から」。その下に項目ごとの金額、NISA は「元本 ¥◯◯・+¥◯◯（+◯%）」
2. **推移の折れ線グラフ**（月ごと。その月の最後の記録）。点を押すとその月の合計が出る
3. **残高（ホームに出る額）の中身**：楽天銀行の記録、引く引き落とし、カード代を引いた額。「記録した日のあとの入金や、カード以外の出入りは入っていない」と書く
4. **記録の一覧**と「記録する」ボタン。1行を押すとその日の記録を直す・消すシート
5. **記録のシート**：記録日（初期値は今日）、楽天銀行の残高、NISA の評価額、NISA の元本。それぞれに「前回 ¥◯◯」を小さく出す。入れなかった項目は送らない（前の記録の金額のまま数える）

### S-11 収入（段階③。ホームの収入のカードから）

1. 今月の収入（大きな数字）と「収入を記録する」ボタン
2. 月ごとの見出し（◯年◯月 と合計）と、入金の一覧。行は名前（なければ「入金」）、日付、+¥◯◯
3. 1行を押すと、名前を変える・手入力なら消すシート。名前の候補（前に使った名前・バイト代・お小遣い）をボタンで出す

統計の棒グラフは「支出／収入」の切り替え（10/6 本人。合計の左のボタン）。切り替えると棒は今の高さから伸び縮みし、色も変わる。下の一覧も、グラフで出しているほうだけにする。円グラフは支出のカテゴリの内訳だけで、合計の下に「収入 +¥◯◯」

### S-12 固定費（10/7 本人。ホームの固定費のカードと、メニューから）

固定費＝グループが「固定費」のカテゴリ（いまはサブスク・通信費）の支出。月は利用日で数える。今日より後の日付と取消は入れない。

1. **今月の固定費の見込み**（大きな数字）＝もう来た分＋まだの分。その下に「先月 ¥◯◯　◯円 多い／少ない／同じ」の1行だけ。出し方は見出しの ⓘ（10/7）
2. **月ごとの固定費**の棒グラフ：データのある月から今月まで、最大12か月。カテゴリごとに固定費の色の濃さを変えて積み上げ、今月はまだ来ていない分を斜線で足す。右に縦の目盛り（S-02 と同じ）。棒をタップすると、ほかの棒が薄くなり、上に「◯月 ¥◯◯」（今月は「見込み ¥◯◯」も）。もう一度タップすると選ぶのをやめる。グラフを左右になぞると、選ぶ月が前後に1つずつ動き、下の一覧もなぞった向きからすべり込む（✅ 10/7 本人：統計と同じように。グラフにある月より先へは動かない）
   - **グラフの下は「◯月の固定費」の一覧1つだけ（✅ 10/7 本人）**：開いたときは今月、棒をタップしたらその月。前の月に「まだ来ていないもの」などが出ると、どの時点の話か分からないため。今月の「来た分」「まだ来ていないもの」「いまの固定費」は、区別が分かりにくいので1つにまとめた（✅ 10/7 本人）
3. **◯月の固定費 ⓘ**：1行＝1回の利用。名前（店の表示名 → この行の名前 → 利用先）が先で、下に日付。月の日にちの順
   - 今月は、まだ来ていないもの（先月来たのに今月まだのもの。同じ店で先月より回数が少ないときは、金額の合わない分）も同じ一覧に入れる。下は「◯日ごろ」（先月来た日）と「まだ」の印、金額は先月の額を薄く。その日を過ぎても来ていなければ「まだ」を赤く。見出しの右は今月の見込み
   - 今月そろった店で、前の月から金額が変わったものは、差（+¥◯◯）を小さく
   - 先月も今月も来ていない店（解約したもの）は出ない（推移には残る）
4. ⓘ には、並べ方と「まだ」の意味、解約・年1回のものの注意
5. 行を押すと、その利用の詳細（S-05）が開く。「まだ」の行は、その店のいちばん新しい利用（先月の分）

### S-05 利用の詳細

日付、利用先、金額、速報／確定の印、支払月（引き落としの月）、カテゴリの選択（グループごとに並べる）、名前の入力、「この店はいつもこの内容」のスイッチ（オンならカテゴリと名前を対応表に入れて同じ店の利用にも付ける、オフならこの1件だけ）。手入力した利用なら「削除」ボタン。

- **保存のしかた（✅ 10/7 本人）**：カテゴリのボタンとスイッチは、押しても選ぶだけ（シートは閉じない）。名前の欄の下の「保存」ボタン1つで、カテゴリ・スイッチ・名前をまとめて保存する。名前の欄で Enter でも保存。何も変えずに押したら閉じるだけ
- 保存を押したら、返事を待たずにシートを閉じて一覧などを先に変える。裏で保存しているあいだは、画面の下に「ぐるぐる＋保存しています…」、終わったら「✓ 保存しました」。失敗したら元に戻して赤で知らせる（03 の 5.1.1）

### S-06 未分類の振り分け

1件ずつカードで出し、下にカテゴリのボタンをグループごとに並べる。押したら次の1件へ進む（返事を待たずにすぐ進み、裏で保存する。10/7）。

### S-07 手入力

上に支出／収入の切り替え（10/6）。収入では、カテゴリの代わりに名前の候補（前に使った名前・バイト代・お小遣い）を出す。

ホームの「記録する」から開く。金額（大きな数字の入力）、日付（今日が初期値）、カテゴリ、メモ。段階③で「支出／収入」の切り替えを足す。

### S-08 メニュー・S-09 CSV・S-10 対応表

飾りは付けず、一覧と入力欄だけのシンプルな画面にする。

**S-09 CSV の照合**（10/6）：メニューの「CSV の取り込みと照合」から。パソコンで使う想定（CSV はパソコン版 e-NAVI からしか取れない）
1. 「CSV を選ぶ」。ファイルはこの端末の中だけで読む
2. 「◯年◯月払いの明細」と、CSV の件数・一致・足す候補・キャンセルかも の4つの数。その下に合計：明細の利用の合計／シートのその月の支払い分の合計（同じなら「✓ そろっています」、違えば「◯円 足りません／多いです」）／キャンセルなど／差し引いた支払金額（e-NAVI の一覧の支払金額と同じになるはず）
3. **CSV にだけある利用**（最初からチェックあり）：店名・日付・付くカテゴリ（対応表）・金額
4. **メールにだけある利用**（最初はチェックなし）：その月の支払い分なのに明細に出てこないもの。キャンセルになったものだけ選ぶ
5. 「反映する（足す ◯件・取り消す ◯件）」。照らし合わせは描くたびに今のデータでやり直すので、反映した行は「一致」に入る。外したチェックは外したまま
6. 「以降」の支払い分（まだ決まっていない分）は数だけ出して、次の月の CSV で照らし合わせる。本人以外・返金（マイナス）の行は読まない

### 説明の出し方（✅ 10/7 本人）

パッと見たときの情報を減らすため、画面に置くのは数字と短い名前だけにし、出し方や注意は **ⓘ（インフォメーションマーク）** に入れる。

- ⓘ を押すと、すぐ下（下に場所がなければ上）に小さな吹き出しで説明が出る。もう一度押す・ほかの場所を押す・スクロールで閉じる。シートの中でも使え、シートは閉じない
- カード全体がリンクのとき（ホームの残高・固定費）は、ⓘ を押してもカードの先へは進まない
- ⓘ に入れたもの：ホームの残高・固定費、固定費の画面（見込み・まだ来ていないもの・いまの固定費）、予算（1日あたり・今日までの目安・予算のシート）、資産（残高・記録のシート）、収入、CSV の照合（初めの説明・各欄・支払金額）、利用の詳細と振り分け（いつもこの内容・名前）、手入力（支出／収入で中身が変わる）、確認が必要な速報、対応表
- 合言葉の画面の注意（締め出し）は、見落とすと困るので画面に出したまま

## 4. PC での配置

- タブバーは画面の**左の縦のメニュー**に変える（ホーム・統計・予算・資産、下にメニュー）
- ホームは2列にする：左に写真と今月の支出、右に支出トップと最近の利用
- 統計は2列にする：左にグラフ、右に利用一覧
- シート（S-05・S-07）は画面の中央に出る小さな窓にする

## 5. 見た目の方針（色づけの前に決めておくこと）

デザイン（色・文字・写真）は、配置が決まってから別に詰める。ここでは方向だけ書いておく。

- 構成は参考画像1・2枚目、雰囲気は3枚目（✅ 要件 N-08）
- 写真を使うのは**ヘッダーと支出トップのカードだけ**。グラフ・一覧・数字の後ろには敷かない
- 色はオフホワイトの背景と、差し色1色、グループの4色
