## 2. 画面遷移

### 2.1 タブバー ✅

```
[ ホーム ]  [ 統計 ]  [ 予算 ]  [ 資産 ]
```

- タブは4つだけ。「＋」は置かない（✅ 10/6）
- 記入が必要なものは、**ホームの「やること」のボタンで促す**（✅ 10/6。中身は S-01 の 5）
- メニュー（S-08）はタブに入れず、ホームの右上のアイコンから開く（✅）
- 段階①の間、予算・資産のタブは「準備中」の画面にする

### 2.2 遷移の一覧

```
起動
 └─ 合言葉が未保存 → S-00 合言葉 → S-01 ホーム
 └─ 合言葉が保存済み → S-01 ホーム

S-01 ホーム
 ├─ 右上のアイコン → S-08 メニュー
 ├─ 目のアイコン → 金額を隠す／出す（F-10。画面は変わらない）
 ├─ やること「未分類が◯件」 → S-06 未分類の振り分け
 ├─ やること「CSV で照合する」（月初だけ） → S-09
 ├─ やること「資産を記録する」（月末だけ・段階③） → S-04 の記録の入力
 ├─ やること「予算を決める」（予算がないときだけ） → S-03 予算
 ├─ 今月の支出のカードの「予算の残り」 → S-03 予算
 ├─ 「記録する」ボタン → S-07 手入力（シート）
 ├─ 支出トップのカード → S-02 統計（そのカテゴリで絞り込んだ状態）
 └─ 最近の利用の1行 → S-05 利用の詳細

S-02 統計
 ├─ 期間の単位の切り替え（週／月／年） → 同じ画面のまま
 ├─ グラフの種類の切り替え（棒／円） → 同じ画面のまま
 ├─ グラフを左右にスワイプ → 前後の週・月・年へ（一覧もその期間に変わる）
 ├─ 棒グラフの棒をタップ → 下の一覧がその期間に絞られる
 ├─ 円グラフのグループをタップ → カテゴリの内訳が開き、一覧もそのグループに絞られる
 └─ 一覧の1行 → S-05 利用の詳細

S-05 利用の詳細（シート）
 ├─ カテゴリを変える → この1件だけ変える（F-12）
 └─ 「この店はいつもこのカテゴリ」をオン → 対応表に登録（F-06）

S-08 メニュー
 ├─ CSV の取り込みと照合 → S-09
 ├─ カテゴリの対応表 → S-10
 ├─ 予算の設定（段階②）
 └─ 合言葉・表示の設定（週の始まり：月曜／日曜）、最終取り込み時刻の表示
```

図にしたものはワイヤーフレームのページの最後にある。

## 3. 各画面の配置

上から順に並べる。はすべて 10/6 に承認済み。

### S-01 ホーム

1. **写真のヘッダー**（画面の上 4割ほど）：季節や月で変わる写真を置き、その上に「10月」と挨拶、右上にメニューと目のアイコン
2. **今月の支出**：写真の下端に重なる白いカードに、大きな数字を1つだけ置く。その下に小さく「先月の同じ日まで：¥◯◯」（✅ 10/6）。予算があるときは、その下に細い横棒（使った割合と今日までの目安の縦線）と「予算の残り ¥◯◯」（✅ 10/6。押すと S-03）
3. **収入・残高の行**：収入｜残高 を横に2つ並べる（段階③までは「—」）
4. **次の引き落とし**：「10/27 引き落とし予定 ¥◯◯」の細い帯
5. **やること**：記入が必要なものがあるときだけ、ボタンの形で出す。何もなければこの欄ごと消える
   - 「未分類が3件あります」→ S-06
   - 「先月分を CSV で照合する」（毎月1〜7日ごろだけ）→ S-09
   - 「今月の資産を記録する」（月末〜翌月初・段階③）→ S-04
   - 「予算を決める」（予算がないときだけ）→ S-03
   - 欄の右端に、いつでも押せる「記録する」（手入力 S-07）
6. **支出トップ**：期間の切り替え（今週／今月）と、横にスクロールするカテゴリのカード。カードにはカテゴリの写真を置き、上に順位・カテゴリ名・金額を載せる
7. **最近の利用**：3件だけ。表示は S-02 の一覧と同じ（用途だけ）

### S-02 統計

1. **見出し**「統計」と、期間の単位の切り替え（週／月／年）
2. **グラフの種類の切り替え**：「棒｜円」の小さな切り替え
3. **期間の表示**：「‹ 2026年10月 ›」。左右の矢印でも、グラフのスワイプでも前後の期間へ動く
4. **グラフのカード**
   - 棒グラフ：支出の棒。選んだ棒だけ色が濃くなり、上に金額が出る。段階③で収入の棒と並べる。棒の単位は、週なら1日ずつ、月なら1週ずつ、年なら1か月ずつ（✅ U-11）
   - 円グラフ（ドーナツ型）：グループ4色で比率を見せ、真ん中に合計。タップでカテゴリの内訳
5. **利用一覧**：日付ごとの見出しの下に「カテゴリの印｜**用途（カテゴリ名）を大きく**＋小さく名前（例：サブスク　YouTube Premium）｜金額」。名前は、この利用だけの名前 → 店の表示名 の順。どちらもなければ用途だけ。利用先（店名）は一覧には出さず、S-05 で見る（✅ 10/6）。絞り込み中は一覧の上に「◯◯で絞り込み中 ×」

> **スワイプがぶつかる問題**：はじめは「棒⇄円」を横スワイプで切り替える案だったが、「前後の期間へスワイプ」も横の動きになる。両方は同じ手の動きに割り当てられないので、**横スワイプ＝期間、棒／円＝切り替えボタン**に分けた。

### S-03 予算（段階②）

予算は全体だけ（U-02 → 10/6 本人）。

1. **今月の残り**：大きな数字（使いすぎたら「オーバー」と、その額を注意の色で）。その下に、使った割合の横棒と、今日までの目安の縦線。「使った ¥◯◯（◯%）」「予算 ¥◯◯」
2. **2つの小さいカード**：「1日あたり」（月末まで、今日を入れて残りの日数で割る。使いすぎたら —）／「今日までの目安」（目安より ◯円 少ない・多い）
3. **予算の決め方**：「毎月の予算」と「◯月だけの予算」の2行。押すと金額を入れるシートが開く。その月だけの予算があれば毎月の予算より優先し、「やめる（毎月の予算に戻す）」で戻せる
4. 予算がないときは、1・2 の代わりに「予算を決める」ボタンの入ったカード

### S-04 資産（段階③）

1. 資産の合計（いちばん新しい記録）
2. 推移の折れ線グラフ（月ごと）
3. 月ごとの記録の一覧（銀行の残高、NISA の評価額）と、記録を足すボタン

### S-05 利用の詳細

日付、利用先、金額、速報／確定の印、支払月（引き落としの月）、カテゴリの選択（グループごとに並べる）、名前の入力、「この店はいつもこの内容」のスイッチ（オンならカテゴリと名前を対応表に入れて同じ店の利用にも付ける、オフならこの1件だけ）。手入力した利用なら「削除」ボタン。

### S-06 未分類の振り分け

1件ずつカードで出し、下にカテゴリのボタンをグループごとに並べる。押したら次の1件へ進む。

### S-07 手入力

ホームの「記録する」から開く。金額（大きな数字の入力）、日付（今日が初期値）、カテゴリ、メモ。段階③で「支出／収入」の切り替えを足す。

### S-08 メニュー・S-09 CSV・S-10 対応表

飾りは付けず、一覧と入力欄だけのシンプルな画面にする。

## 4. PC での配置

- タブバーは画面の**左の縦のメニュー**に変える（ホーム・統計・予算・資産、下にメニュー）
- ホームは2列にする：左に写真と今月の支出、右に支出トップと最近の利用
- 統計は2列にする：左にグラフ、右に利用一覧
- シート（S-05・S-07）は画面の中央に出る小さな窓にする

## 5. 見た目の方針（色づけの前に決めておくこと）

デザイン（色・文字・写真）は、配置が決まってから別に詰める。ここでは方向だけ書いておく。

- 構成は参考画像1・2枚目、雰囲気は3枚目（✅ 要件 N-08）
- 写真を使うのは**ヘッダーと支出トップのカードだけ**。グラフ・一覧・数字の後ろには敷かない
- 色はオフホワイトの背景と、差し色1色、グループの4色
